# 📦 mods/

Elke mod die je in **BlockyMod Studio** maakt, krijgt hier een **eigen map**.
Daar zet ik (de AI) de code in die jij voor die mod vraagt.

```
mods/
├── mijn-eerste-mod/
│   ├── README.md        ← zo maak je de map aan
│   └── ...              ← code die de AI voor je schreef
├── mijn-tweede-mod/
└── ...
```

## Zo maak je een map aan (géén Git nodig)

1. Open deze repo op GitHub → **Add file → Create new file**
2. Typ als bestandsnaam: `mods/jouw-modnaam/README.md`
   (de mappen `mods/` en `jouw-modnaam/` ontstaan vanzelf)
3. Klik **Commit changes**

Of zeg het tegen de AI: *"maak de map mods/jouw-modnaam aan"* – dan doe ik het.

## In de app

Tab **🤖 AI-code / GitHub**:

| Veld | Waarde |
|---|---|
| Eigenaar | `Ven1x-cloud` |
| Repository | `blockymoding` |
| Branch | `main` (of de tak die je gebruikt) |
| Map met AI-codes | `mods/jouw-modnaam` |

Daarna: **Codes ophalen bij GitHub** → de code zit in je mod-export. 🎉
